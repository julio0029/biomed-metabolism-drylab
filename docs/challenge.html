Read the sample. Order the tests. Explain the phenotype.

Use the same simplified bioenergetic arithmetic as the metabolic map. This is a learning exercise, not a diagnostic decision tool.

1. Choose a case

Each case uses a glucose assay, targeted tests and a metabolic phenotype.

Case A · Early reperfusion

A patient has restoration of blood flow after a short period of ischaemia. The task is to identify why oxygen restoration can increase ATP but also increase ROS.

Begin with the glucose result, then order the tests you think are necessary to calculate oxidative output.

Glucose assay: absorbance = 0.100 × [glucose mmol/L] + 0.050
Calculate glucose from the standard curve before moving on.
